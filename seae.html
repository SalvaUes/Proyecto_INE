Criterio: TIR > TMAR → Aceptar · TIR < TMAR → Rechazar · Mayor TIR = mayor rentabilidad intrínseca

VAN = −I₀ + Σ [FCₜ / (1+i)ᵗ] — Equivalente al VPN; nomenclatura internacional (NIIF/IFRS).
Criterio: VAN > 0 → Crea valor · VAN = 0 → Indiferente · VAN < 0 → Destruye valor
